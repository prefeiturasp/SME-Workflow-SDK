Exceções

O pacote excecoes reúne as exceções utilizadas pelo SDK para representar falhas relacionadas à leitura, validação da configuração, validação do domínio e resolução das transições do workflow.

Exceções base

Define as exceções base utilizadas pelo SDK de workflow.

exception sme_workflow_sdk.excecoes.base.LeitorWorkflowError[código-fonte]

Base: Exception

Exceção base para erros relacionados à leitura da configuração.

exception sme_workflow_sdk.excecoes.base.ValidadorWorkflowError[código-fonte]

Base: Exception

Exceção base para erros relacionados à validação da configuração.

exception sme_workflow_sdk.excecoes.base.ValidacaoDominioError[código-fonte]

Base: Exception

Exceção base para erros de validação das entidades de domínio.

Exceções de configuração

Exceções relacionadas à leitura e validação da configuração do workflow.

exception sme_workflow_sdk.excecoes.configuracao.ArquivoNaoEncontradoError[código-fonte]

Base: LeitorWorkflowError

Indica que o arquivo de configuração não foi encontrado ou acessado.

exception sme_workflow_sdk.excecoes.configuracao.FormatoInvalidoError[código-fonte]

Base: LeitorWorkflowError

Indica que o arquivo possui extensão ou estrutura YAML inválida.

exception sme_workflow_sdk.excecoes.configuracao.ConfiguracaoInvalidaError[código-fonte]

Base: LeitorWorkflowError

Indica que o conteúdo YAML não possui uma estrutura válida.

exception sme_workflow_sdk.excecoes.configuracao.EstadoInvalidoError[código-fonte]

Base: ValidadorWorkflowError

Indica que um estado possui nome, estrutura ou referência inválida.

exception sme_workflow_sdk.excecoes.configuracao.AcaoInvalidaError[código-fonte]

Base: ValidadorWorkflowError

Indica que uma ação possui nome, estrutura ou transição inválida.

Exceções de workflow

Exceções relacionadas ao motor do workflow.

exception sme_workflow_sdk.excecoes.workflow.TransicaoInvalidaError[código-fonte]

Base: Exception

Indica uma falha na resolução de uma transição do workflow.
