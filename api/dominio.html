Domínio

O pacote dominio reúne as entidades e os objetos que representam os dados e contratos fundamentais do workflow.

Entidades

Define as entidades de domínio do workflow.

Este módulo disponibiliza as entidades Acao, Estado e Transicao, responsáveis por representar as regras e os elementos que compõem um workflow.

As entidades validam seus atributos durante a inicialização, garantindo a consistência dos dados e a utilização de identificadores válidos para estados e ações.

As classes utilizam dataclasses imutáveis. Quando aplicável, os mapeamentos são protegidos por types.MappingProxyType para impedir alterações diretas após a criação das entidades.

class sme_workflow_sdk.dominio.entidades.Acao(nome, proximo_estado, terminal)[código-fonte]

Base: object

Representa uma ação configurada para um estado do workflow.

Uma ação define uma operação disponível em determinado estado, especificando seu nome, o estado de destino após sua execução e se a transição representa o encerramento do workflow.

Os nomes da ação e do estado de destino devem seguir o padrão de identificadores do domínio, contendo letras ASCII e palavras separadas por sublinhados.

A entidade é imutável após sua criação.

Variáveis:

  • nome (str) – Nome da ação disponibilizada no estado atual.

  • proximo_estado (str) – Nome do estado para o qual a execução deve avançar.

  • terminal (bool) – Indica se a transição representa o encerramento do workflow.

Parâmetros:

  • nome (str)

  • proximo_estado (str)

  • terminal (bool)

nome: str
proximo_estado: str
terminal: bool

Valida os atributos da ação após sua inicialização.

Verifica se nome e proximo_estado são strings não vazias e se seguem o padrão de identificadores definido pelo domínio.

Também verifica se terminal é estritamente do tipo booleano, não aceitando valores inteiros como 0 e 1.

Levanta:

class sme_workflow_sdk.dominio.entidades.Estado(nome, acoes)[código-fonte]

Base: object

Representa um estado do workflow.

Um estado identifica uma etapa do processo e define as ações disponíveis para avançar a execução.

O atributo acoes pode receber um mapeamento entre os nomes das ações e suas respectivas entidades Acao, ou None quando não houver ações associadas ao estado.

O mapeamento informado é copiado e convertido em types.MappingProxyType, impedindo alterações diretas nas chaves e nos valores armazenados. Essa proteção é superficial e não garante a imutabilidade profunda dos objetos internos.

A entidade é imutável após sua criação.

Variáveis:

  • nome (str) – Identificador do estado do workflow.

  • acoes (Mapping[str, Acao] | None) – Mapeamento entre os nomes das ações e suas respectivas entidades Acao. Pode ser None quando não houver ações.

Parâmetros:

  • nome (str)

  • acoes (Mapping[str, Acao] | None)

nome: str
acoes: Mapping[str, Acao] | None
__post_init__()[código-fonte]

Valida os atributos do estado e protege suas ações.

Verifica se nome é uma string não vazia e segue o padrão de identificadores definido pelo domínio.

Verifica se acoes implementa collections.abc.Mapping ou é None.

Quando o mapeamento está presente, valida os nomes das ações, verifica se cada valor é uma instância de Acao e cria uma cópia protegida por types.MappingProxyType.

Levanta:

ValidacaoDominioError – Se o nome do estado, o mapeamento, algum nome de ação ou alguma entidade de ação for inválido.

Tipo de retorno:

None

Contexto de execução

class sme_workflow_sdk.dominio.contexto.ContextoExecucao(autor, identificador=<factory>, dados=dict())[código-fonte]

Base: object

Representa o contexto associado a uma execução do workflow.

Armazena a identificação do autor, um identificador único da execução e dados adicionais fornecidos pela aplicação consumidora.

Quando não informado, o identificador é gerado automaticamente utilizando uuid.uuid4(). A aplicação consumidora também pode fornecer seu próprio identificador, desde que seja uma string não vazia.

A instância é imutável após sua criação. O atributo dados é copiado e convertido em types.MappingProxyType, impedindo alterações diretas no mapeamento armazenado.

A cópia dos dados é superficial: objetos mutáveis armazenados como valores não são copiados recursivamente e podem continuar sendo modificados por referências externas.

Variáveis:

  • autor (str) – Identificação do autor responsável pela execução. Deve ser uma string não vazia.

  • identificador (str) – Identificador único da execução. Caso não seja informado, um uuid.uuid4() é gerado automaticamente.

  • dados (Mapping[str, Any]) – Mapeamento com informações adicionais da execução. Por padrão, é inicializado com um dicionário vazio.

Parâmetros:

  • autor (str)

  • identificador (str)

  • dados (Mapping[str, Any])

autor: str
identificador: str
dados: Mapping[str, Any]
__post_init__()[código-fonte]

Valida os atributos e protege o mapeamento de dados.

Valida se autor e identificador são strings não vazias e se dados implementa a interface Mapping.

Após as validações, cria uma cópia superficial do mapeamento informado e o converte em types.MappingProxyType, impedindo alterações diretas nas chaves e nos valores do mapeamento armazenado.

Levanta:

ValidacaoDominioError – Se algum atributo não atender às regras de validação ou se os dados não puderem ser convertidos em um dicionário.

Tipo de retorno:

None

class sme_workflow_sdk.dominio.execucao_validada.ExecucaoValidada(estado_atual, acao, inicio_transicao=<factory>)[código-fonte]

Base: object

Representa uma transição de workflow previamente validada.

Armazena os dados necessários para identificar uma transição autorizada pela configuração do workflow, incluindo o estado atual, a ação correspondente e o horário de início.

A instância é imutável após sua criação. Quando o horário de início não é informado, ele é gerado automaticamente utilizando UTC.

Variáveis:

  • estado_atual (str) – Nome do estado em que a transição será executada. Deve ser um identificador válido.

  • acao – Instância de Acao contendo as informações da ação validada e seu próximo estado.

  • inicio_transicao (datetime) – Data e hora de início da transição, com fuso horário definido. Por padrão, utiliza o horário atual em UTC.

Parâmetros:

  • estado_atual (str)

  • acao (Acao)

  • inicio_transicao (datetime)

acao: Acao
inicio_transicao: datetime

Também verifica se a ação é uma instância de Acao e se o horário de início é um objeto datetime com fuso horário definido.

Levanta:

Resultado do workflow

class sme_workflow_sdk.dominio.resultado.ResultadoWorkflow(identificador, estado_anterior, acao, proximo_estado, terminal, sucesso, mensagem, inicio, fim, autor, contexto)[código-fonte]

Base: object

Representa o resultado de uma execução do workflow.

Reúne as informações necessárias para identificar uma execução, descrever a transição solicitada e registrar seu resultado.

A entidade é imutável após sua inicialização. Suas validações verificam os tipos e valores dos atributos, a compatibilidade dos horários e a consistência da transição.

Uma execução bem-sucedida e não terminal deve indicar um estado de destino diferente do estado anterior. Execuções malsucedidas podem manter o estado anterior como próximo estado.

Variáveis:

  • identificador (str) – Identificador único da execução.

  • estado_anterior (str) – Nome do estado em que a ação foi executada.

  • acao (str) – Nome da ação executada.

  • proximo_estado (str) – Nome do estado resultante da execução.

  • terminal (bool) – Indica se a transição encerra o workflow.

  • sucesso (bool) – Indica se a execução foi concluída com sucesso.

  • mensagem (str) – Mensagem complementar sobre o resultado.

  • inicio (datetime) – Data e hora de início da execução.

  • fim (datetime) – Data e hora de término da execução.

  • autor (str) – Identificação do autor responsável pela execução.

  • contexto (ContextoExecucao) – Contexto associado à execução, representado por uma instância de ContextoExecucao.

Parâmetros:

  • identificador (str)

  • estado_anterior (str)

  • acao (str)

  • proximo_estado (str)

  • terminal (bool)

  • sucesso (bool)

  • mensagem (str)

  • inicio (datetime)

  • fim (datetime)

  • autor (str)

  • contexto (ContextoExecucao)

Valida os atributos e a consistência do resultado.

Verifica os tipos e valores dos atributos obrigatórios, a validade dos identificadores e a consistência dos horários.

Também verifica se o horário de término não é anterior ao horário de início e se uma execução bem-sucedida e não terminal aponta para um estado diferente do estado anterior.

_converter_para_dict(valor)[código-fonte]

Converte recursivamente estruturas de dados em valores simples.

Converte dataclasses em dicionários, mapeamentos em dicionários comuns, listas e tuplas em listas e enums em seus respectivos valores.

A conversão é recursiva, permitindo tratar estruturas aninhadas. Tipos não contemplados pelas conversões são preservados, incluindo objetos datetime.

Parâmetros:

valor (Any) – Valor a ser convertido.

Retorna:

Valor convertido conforme seu tipo, preservando os objetos que não possuem uma regra específica de conversão.

Tipo de retorno:

Any

para_dict()[código-fonte]

Converte o resultado do workflow em um dicionário.

Percorre recursivamente os atributos do resultado, convertendo dataclasses, mapeamentos, listas, tuplas e enums para estruturas equivalentes em tipos básicos.

Os objetos datetime são preservados, não sendo convertidos automaticamente para strings.

Retorna:

Dicionário contendo os atributos do resultado, incluindo os objetos datetime originais e o contexto convertido recursivamente.

Tipo de retorno:

dict[str, Any]

Validações

Disponibiliza funções genéricas para validação de dados do domínio.

Este módulo reúne funções reutilizáveis para validar tipos, strings, valores booleanos, mapeamentos e identificadores utilizados pelas entidades do workflow.

As funções centralizam as regras básicas de validação e lançam ValidacaoDominioError quando os valores informados não atendem aos critérios estabelecidos.

sme_workflow_sdk.dominio.validacao.validar_identificador(valor, nome_campo)[código-fonte]

Valida o formato de um identificador de estado ou ação.

Aceita somente letras ASCII , com palavras separadas por sublinhados. Cada palavra deve conter pelo menos uma letra.

Não são permitidos números, espaços, hífens, caracteres acentuados, sublinhados no início ou no fim, nem sublinhados consecutivos.

Exemplos de identificadores válidos:

  • pendente

  • em_execucao

  • aguardando_aprovacao

Exemplos de identificadores inválidos:

  • em-execucao: contém hífen.

  • estado2: contém número.

  • em execução: contém espaço.

  • em_execução: contém caractere acentuado.

Parâmetros:

  • valor (str) – Nome do estado ou da ação a ser validado.

  • nome_campo (str) – Nome do campo usado na mensagem de erro.

Levanta:

ValidacaoDominioError – Se o identificador não respeitar o padrão definido pelo domínio.

Tipo de retorno:

None
